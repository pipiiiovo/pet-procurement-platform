2项目概述与目标

2.1 业务背景

宠物零售终端（宠物店、宠物医院、商超宠物专区、电商宠物店铺）的采购长期依赖多级经销商，存在价格不透明、起订量高、品类分散、对账低效、售后无保障等痛点。平台通过聚合品牌方/经销商（供应商）与终端门店（零售商），以线上化的方式完成"看得见价格 → 下得了单 → 付得了款 → 查得到物流 → 退得了货"的完整闭环。

2.2 产品定位

供应商（供给侧）

品牌方 / 一级经销商 / 工厂。提供货品与价格，接受平台审核与履约考核，获取订单与结算。

零售商（需求侧）

各类终端门店。通过资质认证后可见拿货价，享受一站式比价、下单、物流追踪与售后。

平台（运营侧）

规则制定者与服务方。负责准入审核、商品治理、自营独代经营、资金与物流履约保障、纠纷仲裁。

2.3 业务目标（KPI）

指标目标值口径说明
供应商入驻转化≥ 60%提交入驻申请 → 审核通过的比例，审核时效 ≤ 2 个工作日
商品上架审核时效≤ 4 小时供应商提交 → 平台审核完成的 P90 时长
零售商复购率≥ 45%近 90 天内下单 ≥ 2 次的零售商占比
订单履约准时率≥ 95%承诺时效内完成签收的订单占比
售后完结率≥ 90% / 72h售后工单 72 小时内完结占比
独代商品毛利贡献≥ 25%独代商品毛利 / 平台总毛利

2.4 用户画像与场景

角色典型用户核心场景关键诉求
供应商某宠物品牌区域经销商（运营 1-3 人）批量导入 SKU、设置阶梯价、处理门店订单与发货、月度对账开票铺货效率、回款确定性
零售商宠物店店主（手机为主）补货比价、凑单达到起订量、微信支付、查看快递到哪了、临期破损退货低价、省心、可追溯
平台运营品类运营 / 审核专员 / 客服 / 财务审核资质与商品、上架独代品、处理异常订单与退款仲裁、配置活动与公告效率、风控、数据可追溯

4核心业务流程总览

4.1 供应商入驻链路

注册账号→ 填写企业信息→ 上传资质材料→ 签署平台协议→ 平台初审→ 资质核验（工商/风控）→ 通过：开通后台／ 驳回：原因回填可重提

4.2 商品上架链路

供应商创建商品→ 平台内容审核→ 价格与合规审核→ 上架（在售）→ 零售商可见可购

※ 平台自营独代商品跳过供应商环节：平台运营直接创建 → 内部复核 → 上架，成本价字段仅财务/超管可见。

4.3 交易履约链路

加购→ 校验 MOQ / 库存 / 资质→ 提交订单→ 在线支付→ 支付成功（分账挂账）→ 供应商接单备货→ 发货回填运单→ 物流在途（轨迹可查）→ 确认收货→ 到账结算 / 可开票

※ 超时未支付（默认 30 分钟）自动关单并释放库存；超时未发货（默认 48 小时）触发预警与商户扣分，超时可由零售商发起退款。

4.4 售后退款链路

零售商发起售后（仅退款 / 退货退款）→ 供应商处理（48h）→ 同意：退货 → 验货 → 退款／ 拒绝→ 平台介入仲裁→ 判定退款 / 驳回→ 原路退回 + 结算冲抵

9核心状态机定义

9.1 资质审核状态

未提交→ 待审核→ 审核中（核验/补件）→ 已通过／ 已驳回（可重提）→ 资质过期 / 冻结

9.2 商品状态

草稿→ 待审核→ 在售↔ 已下架（供应商自主） ｜审核驳回｜ 平台强制下架（违规）

※ 供应商与平台自营商品共用状态机；独代商品新增"内部复核"节点，通过后直接进入在售。

9.3 订单状态（主状态）

状态触发条件可执行动作
待付款提交订单成功支付、取消订单、超时 30min 自动关闭
待接单支付成功供应商接单/拒单、超时 48h 预警并可强制退款
备货中供应商已接单发货、缺货协商
待发货支付成功且未填运单发货（回填承运商+运单号）
已发货运单回填成功查看物流；发货后 15 天自动确认收货
已签收 / 已完成零售商确认或自动确认评价、申请售后（7 天内）、开票、触发结算
退款中 / 已退款售后通过退货物流回填、平台退款、结算冲抵
已关闭超时未付 / 取消 / 拒单库存回滚，不可恢复

9.4 售后/退款状态

待供应商处理→ 待买家退货→ 待卖家收货验货→ 待平台退款→ 退款成功 ｜已拒绝→ 平台介入中→ 仲裁完成

9.5 结算状态

待结算（担保中）→ 可结算（T+N 到期）→ 结算单待确认→ 财务复核→ 已打款→ 已开票

14.2 风控规则（节选）

  • 价格异常：上架价高于建议零售价、或 24h 内涨幅 > 15% 时进入人工复核。
  • 异常下单：同一零售商 1 小时内 > 10 单、单笔金额 > 预设阈值（如 ¥50,000）、收货地址频繁变更 → 触发人工复核。
  • 刷单识别：供应商与零售商关联（同设备/同银行卡/同 IP 段）下单不计入销量与结算。
  • 资质到期：到期前 30 天提醒，到期当日限制新品上架，逾期 15 天冻结提现。
  • 违规处罚：售假/虚假发货/辱骂客服 → 扣分，累计达阈值下架商品、冻结店铺、终止合作。

14.3 待确认事项（Open Issues）

  1. 是否引入担保交易（确认收货后再结算）作为默认模式，或按供应商协议差异化。
  2. 独代商品的仓储与发货由平台云仓执行，还是由代工供应商代发（影响物流与结算模型）。
  3. 是否需要对接零售商 ERP / 收银系统，以及开放 API 的范围与鉴权方式。
