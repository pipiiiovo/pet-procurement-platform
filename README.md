# 宠采通 · 宠物用品采购平台

面向供应商（品牌方 / 经销商）、零售商（宠物店 / 宠物医院 / 商超宠物专区）与平台管理方的
B2B 宠物用品采购平台交付物：**需求规格说明书 + 可交互高保真原型**。

纯静态零依赖（原生 HTML / CSS / JS），无需构建、无需后端，直接打开即可演示。

## 在线入口

| 页面 | 路径 |
| --- | --- |
| 交付门户（推荐入口） | `index.html` |
| 需求文档 PRD | `prd.html` |
| 可交互原型 | `prototype/index.html` |

## 内容概览

- **需求文档**：14 章，含三方角色权限矩阵、五大核心链路、S / R / P / C 功能清单（P0/P1/P2）、
  资质 / 商品 / 订单 / 售后 / 结算 5 套状态机、数据模型与非功能需求。
- **可交互原型**：三端 34 个页面全部可点击跳转，业务数据跨角色实时联动。
  - 供应商端：入驻资质、商品管理与上架、订单发货、售后、结算
  - 零售商端：资质解锁拿货价、搜索比价、阶梯价、购物车、下单支付、物流、售后
  - 平台端：三类审核、独代商品、订单 / 退款 / 财务、物流、工单、平台维护
- **演示数据**保存在浏览器 localStorage，顶栏可一键重置。

## 建议体验动线

1. 平台端「商品上架审核」通过一款宠物零食
2. 零售商端首页可见该商品 → 加入购物车 → 下单支付
3. 供应商端「订单管理」接单并回填承运商与运单号发货
4. 零售商端「物流查询」查看轨迹 → 确认收货
5. 「我的订单 → 订单详情」发起售后 → 供应商处理 → 平台端退款仲裁

## 说明

- 原型为演示用途，不含真实支付、实名与物流对接。
- 页面基于 hash 路由（`#/角色/页面`），可直接分享具体页面链接。
